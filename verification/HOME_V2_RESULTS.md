# Общий дом v2 — фактические проверки, 2026-11-07

## Реализовано

Android: Mesh.kt + новый HomeLink.kt, Engine/Tools/Entry интеграция, Screen/Copy членство на девяти языках. Все 9 Kotlin-файлов синхронизированы в amalia-3.0/examples/native/unified-home.

ПК: examples/plugins/unified-home/mesh.py, runtime.py, api.py, __init__.py, panel/*; усилены models.py/scenes.py для корректной проверки удалённых планов и честных статусов.

## Проверено

- Полный существующий набор тестов ПК после окончательных изменений: **71 passed**, один dependency deprecation warning (плюс pytest-asyncio configuration warning).
- Настоящие loopback UDP-сокеты трёх PC runtime: аутентифицированное объявление → каталог → план → чужой владелец получает отказ → владелец применяет → confirmed симуляторов → повтор токена отклонён. Отказ remote apply консервативно помечен unknown.
- Отдельные ephemeral-проверки: чужой дом не принимается; модифицированное тело и повтор nonce отклоняются; ключ не попадает в публичный snapshot; leave очищает участников/сессию.
- Локальные REST-членство create/export/leave/join прошли через TestClient с loopback client/Host и заголовком local-ui. Нет заголовка и cross-origin Origin дают 403. Export no-store, приглашение отсутствует в overview.
- Kotlin PSI parser всех 9 файлов: **0 синтаксических ошибок**. Это НЕ проверка типов, Compose ABI или сборка JAR.
- `node --check panel/panel.js` без ошибок.
- Все 9 Kotlin-файлов идентичны CI-копии; новые строки членства присутствуют в девяти локалях.
- `git -C /root/amalia-3.0 diff --check` без замечаний.
- Новые test-файлы не добавлялись. Проверки UDP/REST выполнялись временными командами с временными хранилищами, пользовательские дома/железо не менялись.

## Не проверено / ограничения

- Android exact-host SDK отсутствует. Android JAR/DEX, подписанный пакет, активация, Android↔ПК реальный обмен и UI/доступность на телефоне не проверены. APK не собирался.
- UI веб-панели проверен по исходникам/JS-синтаксису, не браузерной автоматизацией.
- HMAC не шифрует LAN; общий ключ означает равные права участников, локальная UI-защита ПК не заменяет login-систему. Не публиковать хост ПК напрямую в интернет.
- Старый v1/handoff намеренно несовместим. Диагностическое голосование не связано с VAD/микрофоном. Это не готовый общий голосовой конвейер.
- У ПК-хоста ещё нет интегрированного lifecycle сетевого runtime с переключателем плагина/стартом приложения. Участие начинается при обращении к панели/инструментам; явный leave прекращает членство.
- Устройства должны иметь согласованное время (окно timestamp ±60 секунд). UDP/firewall/Wi-Fi isolation/Android sleep могут препятствовать доставке.
